I design and build integration platforms for Microsoft Dynamics 365 Business Central — from AL extensions

### What I work on

- 🧩 **Business Central / AL** — extension development, upgrades from legacy NAV customizations
- 🔌 **Integration architecture** — queueing, retry, idempotency, error handling, logging & monitoring for BC ⇄ external systems
- ☁️ **Azure middleware** — Azure Functions (C# / .NET, isolated worker), Key Vault + Managed Identity, OAuth 2.0
- ⚙️ **DevOps for BC** — AL-Go for GitHub, GitHub Actions, environment-gated deployments (Sandbox → Production)
- 🌐 **Adjacent full-stack work** — Next.js/TypeScript portals and embedded viewers that sit in front of BC
- 🇵🇭 **Localization** — automating Philippine statutory tax logic inside BC
